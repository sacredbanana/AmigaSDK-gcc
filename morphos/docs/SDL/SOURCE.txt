SDL2 / SDL3 for MorphOS (BeWorld)
=================================

Source:   https://github.com/BeWorld2018/SDL (branches release-2.32.x-MOS, releas-3.4.x-mos-lib)
Packages: https://www.morphos-storage.net/ (Dependencies/Library/SDL)
  SDL_2.32.11_Libraries.lha  2026-10-07  SDL2 2.32.11 + SDL2_image, _mixer, _ttf, _net, _gfx  (MorphOS 3.19+)
      sha256 aeaee6148b09577c12ee4e7c1848c156e5d6145989f6dcbd7fdaf392d5c5b818
  SDL_3.4.18_Libraries.lha   2026-10-27  SDL3 3.4.18 + SDL3_image 3.4.9, _mixer 3.3.0, _ttf 3.3.0  (MorphOS 3.20+; no SDL3_net yet)
      sha256 d6ea2a790325de3ff801f7371bc934ae24b8f9720434fe3ddfd5957e429f078c

Only each archive's SDK/ directory is installed, into usr/ (bin/sdl2-config, include/, lib/,
lib/libb32/). The libraries are glue for the shared sdl2*.library / sdl3*.library, which the
user installs from the same package; programs link with -noixemul, e.g.
  ppc-morphos-gcc -noixemul prog.c -lSDL3 -lGL
